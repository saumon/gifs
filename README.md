# Nothing to See

A minimalist static web page with a neo-retro aesthetic, designed for GitHub Pages.

## Overview

This project features a simple "Nothing to see" message displayed within a classic System 6/7 style window. It utilizes [system.css](https://github.com/sakofchit/system.css) to achieve its distinctive vintage Macintosh look.

## Features

- **Neo-Retro Styling**: Authentic 1984-era Macintosh interface design.
- **Responsive Layout**: The main window is perfectly centered on the screen.
- **Interactive Window**:
    - **Draggable**: Move the window around the desktop.
    - **Resizable**: Toggle between default and full-screen mode.
    - **Closable**: Hide the window with the close button.
- **Dynamic Desktop Icons**:
    - Automatically fetches GIF files from the repository's `assets` folder using the GitHub API.
    - Displays them as clickable desktop icons.
    - Opens selected GIFs in the main window.
- **Custom Favicon**: Includes a pixel-perfect apple icon.
